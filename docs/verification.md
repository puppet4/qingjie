# 0.1.0 验证记录

本次统一版本标识为 0.1.0，并修复标题栏关闭命令在嵌套消息处理中被拦截的回归。

- 27 项沙箱回归测试通过，包括 PNG 故障写入、原文件保护、活动笔画撤销、窗口重入及销毁、帮助页与应用图标、125%/150%/200% 布局往返、绘图缓存像素一致性及独立进程中的 GDI 对象数量检查。
- 此前已完成真实 Windows 桌面权限下的全局快捷键注册、交换和冲突回退测试通过；只使用临时消息窗口和非常用组合键，没有写入用户配置。
- `cargo clippy --offline --all-targets -- -D warnings` 通过。
- 发布程序为 Windows GUI 子系统，包含原生图标资源；设置窗口同时设置大、小图标。Windows 可从发布文件提取两种尺寸的图标。
- `dist/qingjie.exe` 与 release 构建、`dist/release.json` 中的 SHA256 一致；发布目录只有一个可执行文件。
- 设置、编辑快捷键、帮助及自定义颜色页面已用原生窗口渲染生成预览并检查。

实际混合 DPI 多显示器之间的拖动、HDR 和受保护桌面没有完成实机覆盖。DPI 验证覆盖逻辑布局、控件字体、工具栏绘制和像素一致性，不等同于所有显示器组合的端到端验收。

本轮新增：六种按钮文案在 96/120/144/192 DPI 下的像素边界居中检查、原生按钮悬停进入/离开、非法颜色输入禁用状态验证。常规、悬停、按下、禁用状态见 `controls-preview.png`。系统快捷键注册逻辑本轮未改动，沙箱测试仍跳过该项。

关闭行为回归：先复现设置窗口的 WM_SYSCOMMAND / SC_CLOSE 不能销毁窗口；修复后覆盖三个设置页面的直接关闭、标题栏系统关闭及 Alt+F4，以及颜色窗口的系统关闭和取消语义。已有嵌套销毁安全测试同时保留。

## 发布体积优化

- 同一工具链、x64 release：299,520 → 259,072 字节（292.5 → 253 KiB），减少 40,448 字节，约 13.5%。版本仍为 0.1.0。
- `opt-level` 从 `s` 调整为 `z`；保持 LTO、单代码生成单元、符号裁剪和 panic abort。
- 导出限定为 RGBA8 / 非交错 PNG，使用原来相同的 Sub 滤波、fdeflate 压缩和不可压缩数据回退。通用 png 编码器移到开发/构建依赖；标准 PNG 容器写入使用 crc32fast 校验和 64 KiB IDAT 分块。图标使用构建时生成的 PNG 资源，保留像素与透明度。
- 30 项常规测试通过，另有 1 项手动性能测试默认忽略，1 项全局快捷键注册测试因需要交互桌面而跳过；Clippy all-targets / `-D warnings` 通过。
- 新增独立 PNG 解码及原编码器差分测试：单像素、单行/列、奇数尺寸、跨 IDAT 分块、透明度及确定性噪声；解码像素和拼接后的压缩流均一致。覆盖非法尺寸、长度不匹配、写入失败及单独 flush 失败。
- 手动 release 性能测试：1920×1080 模拟界面/随机噪声，各编码 12 次。原版 `s` 编码路径平均约 5.24 / 26.76 ms，新版 `z` 路径约 4.92 / 25.78 ms；单机短测仅用于排查明显回退，不代表真实截图全流程性能。新路径的 IDAT 分块使这两张 PNG 分别增加 24 / 1,512 字节（不超过 0.02%），像素及压缩流相同。

复现：`cargo test --offline --locked -- --test-threads=1 --skip registration_swap_and_conflict_preserves_old_bindings`；性能对比使用 `cargo test --offline --locked --release compare_png_encoding_cost -- --ignored --nocapture`。PNG 容器格式依据 [W3C PNG 规范](https://www.w3.org/TR/png/)。
