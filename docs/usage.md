# 轻截 Qingjie 0.1.0

Rust 原生 Windows 10/11 本地截图工具。无需 WebView，不上传图片，不运行后台 OCR 模型。

## 运行与设置

运行 `dist/qingjie.exe`，点击托盘图标截图。右键托盘 → **快捷键设置**：

- 点击快捷键输入框，按下新组合键；也可输入 `Ctrl+Shift+A` 等名称。
- 支持 Ctrl / Alt / Shift + 字母、数字、F1–F24，以及 PrintScreen；不支持 Win 修饰键。
- 点击「保存并应用」立即生效，下次启动自动加载。
- 相同快捷键禁止重复分配；被其他软件占用或配置保存失败时，保留原绑定。
- 「恢复默认」只修改表单，点击保存后才生效。
- 配置位于 `%APPDATA%\Qingjie\settings.ini`，按临时文件 + 原子替换写入。
- `qingjie.exe --settings` 直接打开设置。新版本启动前请从托盘退出旧版。

| 功能 | 默认全局快捷键（可修改） |
| --- | --- |
| 区域截图 | Ctrl+Alt+A |
| 全屏截图（全部显示器） | Ctrl+Alt+F |
| 上次区域截图 | Ctrl+Alt+R |
| 延时 3 秒截图 | Ctrl+Alt+D |

上次区域只在当前运行期间保留，记录屏幕绝对坐标；显示器布局变化后会裁剪到当前虚拟桌面范围。首次使用此功能前需要完成一次区域选择。启动注册失败会显示错误，仍可从托盘操作或修改快捷键。

## 自定义颜色

点击截图工具栏色板右侧「＋」，或按 `C` 打开自定义颜色窗口。支持 `#RRGGBB`（也可不输入 #）和 0–255 的 R/G/B 数值，输入时预览和两种格式实时同步。「打开色板」提供系统调色面板。

确定后颜色用于新的画笔、矩形、椭圆、箭头和文字；取消不改变当前标注颜色。预设色之外的当前颜色会显示在「＋」色块上。非法输入不能提交。实色遮挡仍固定使用深色，马赛克按图像采样。本次运行期间保留当前颜色和系统色板的自定义色，重启后恢复默认；不影响已有标注。

## 截图编辑快捷键

这些快捷键仅在截图编辑期间有效，当前为固定映射；设置中的「编辑快捷键」页可查看。

| 操作 | 按键 |
| --- | --- |
| 选择 / 移动 / 调整选区 | V；拖动选区内部移动，拖动边缘或角落缩放 |
| 重新选择 | V 后在选区外拖动 |
| 画笔 / 矩形 / 椭圆 / 箭头 | P / R / O / A |
| 文字 / 马赛克 / 实色遮挡 | T / M / B |
| 选颜色 | 1–8，或点击色板；C / ＋ 自定义颜色 |
| 调整线宽 | + / -，或工具栏按钮；1–12 px，影响新标注 |
| 微调选区 | 方向键，每次 1 px；Shift 加速到 10 px |
| 调整选区尺寸 | Ctrl+方向键；可叠加 Shift |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 复制 / 保存 PNG / 置顶贴图 | Enter 或 Ctrl+C / Ctrl+S / Ctrl+T |
| 取消截图 | Esc 或右键 |

输入文字时 Enter 提交，Esc 放弃本次文字输入。贴图可拖动，右键或 Esc 关闭。取消保存对话框会保留编辑内容。选区调整会改变裁剪范围，已有标注保持原屏幕位置。敏感信息建议使用实色遮挡。

## 界面

设置、编辑快捷键和使用帮助共用一套紧凑布局：在 100% 缩放下内容区为 704×480，正文 13、辅助文字 12、标题 18。设置、帮助、颜色窗口和截图工具栏按窗口 DPI 调整尺寸；跨显示器移动设置窗口会重新布局。文字由 GDI 在目标像素尺寸直接绘制，不做位图拉伸。中文使用 Microsoft YaHei UI，英文使用 Segoe UI；不修改系统字体。

使用帮助从托盘菜单或设置侧栏打开，支持 `qingjie.exe --help`。窗口大小图标、任务栏和可执行文件均使用轻截图标。


采用办公应用风格：浅灰侧栏、白色内容区、蓝色选中态、统一字体和对齐的快捷键表单。截图界面使用半透明遮罩，保留桌面细节；图片导出不包含遮罩、边框或工具栏。工具栏为细线图标，提供选中/禁用状态和悬停提示。拖动期间隐藏工具栏；窄屏自动换行。

参考：[飞书截图功能](https://www.feishu.cn/hc/zh-CN/articles/319286513754)、[飞书快捷键设置](https://www.feishu.cn/hc/zh-CN/articles/894529368028)。

`docs/settings-preview.png` 由原生设置窗口渲染生成；`docs/ui-preview.png` 使用正式截图渲染函数和模拟桌面生成，不包含用户真实桌面。

## 构建与验证

需要 Rust stable（1.88+）、Visual Studio C++ 构建工具和 Windows SDK。脚本优先使用项目 `.tools` 内工具链，否则使用 PATH 中 Cargo。

```powershell
./build.ps1 build
./build.ps1 test
./build.ps1 run
./build.ps1 package
```

`package` 会构建并校验 GUI 可执行文件，原子替换 `dist/qingjie.exe`，同步说明和 SHA256 清单，并清理该目录内旧的版本化程序。程序正在运行而无法替换时，保留现有版本并报告原因。

测试覆盖：选区边界、移动缩放、遮罩细节、裁剪与遮挡像素、快捷键解析和重复校验、配置原子保存与重新读取、真实 Windows 快捷键交换及冲突回退、工具栏边界和原生设置渲染。系统快捷键测试需要普通交互桌面权限；受限沙箱可能拒绝 RegisterHotKey。临时测试配置写在 `target/settings-tests`，不会修改用户配置。

## 资源与边界

当前 x64 发布程序为 259,072 字节（253 KiB），相比精简前的 299,520 字节减少约 13.5%。发布构建采用体积优化、LTO 和符号裁剪；PNG 导出仅保留截图所需的 RGBA8 路径，沿用原来的无损压缩算法。图标在构建时无损压缩，不改变外观；通用 PNG 库仅用于构建和测试。无需安装、额外解压或携带开发工具链，使用 `dist/qingjie.exe` 即可。体积数据对应本仓库当前工具链，升级编译器后可能变化。

后台通过 Windows 消息循环等待事件，不轮询屏幕；截图时才读取画面。截图结束释放图像和编辑状态，贴图保留裁剪图像。工具栏局部使用 2× 超采样绘制矢量图标，无持续 GPU 渲染。编辑内存随显示器像素总数增长。

仅支持 Windows。尚未实现 OCR、滚动长截图、窗口吸附、历史记录、贴图缩放、开机启动、编辑快捷键自定义。HDR、安全桌面和受保护视频不保证正确采集。混合 DPI 多屏及完整鼠标/键盘端到端操作仍需实机验收。

代码：`geometry.rs` 处理选区；`win.rs` 处理采集/编辑/剪贴板；`ui.rs` 绘制截图界面；`color.rs` 处理颜色选择与转换；`settings.rs` 处理配置、原生设置窗口和快捷键事务。`render.rs` 负责画面合成与缓存；`window.rs` 管理窗口状态借用与销毁；`export.rs` 完成编码、刷新和原子替换；`dpi.rs` 统一逻辑尺寸与 DPI 布局；`tools.rs` 定义编辑工具与按键。所有 Win32 FFI 集中在 Windows 模块中。

## 稳定性修复

- PNG 完整编码并确认刷新、写盘后才替换目标；失败保留原文件和编辑状态。
- 活动笔画在松开鼠标后才进入历史，拖动中撤销取消当前笔画，切换工具提交当前笔画，失去鼠标捕获取消未完成笔画。
- 全局快捷键只在前台设置窗口的快捷键输入框中被录制，切换到其他应用仍可正常截图。
- 贴图使用独立窗口类，第二次启动只定位后台控制窗口；设置通过弱引用访问拥有者，窗口销毁时不再悬空访问。
- Win32 回调通过可重入保护访问状态；嵌套销毁延迟释放状态，颜色字段同步不创建重叠独占引用。
- 会话内复用画布、缓存已完成标注和常用字体，更新选区及工具栏区域；截图结束释放图像缓存，贴图直接绘制原图。没有标注时不分配标注缓存。
- 增加故障写入、原文件保护、活动撤销、重入销毁、图标、帮助页、缓存像素一致性及实际 GDI 资源计数回归验证。

## 界面细节

按钮文字按控件矩形水平、垂直居中，统一为 32 逻辑像素高度；不同文案长度和 100%/125%/150%/200% 缩放均进行像素边界验证。侧栏使用图标及垂直居中的左对齐文字；页脚操作统一间距，帮助页的关闭按钮位于右下角。编辑快捷键按工具与操作分组，并使用键帽展示。输入框有焦点与悬停边框，按钮具有正常、悬停、按下和禁用状态；非法颜色输入会禁用确定按钮。工具栏的加减号、色板入口和线宽数值使用同一套居中规则。

标题栏关闭按钮及 Alt+F4 使用标准系统关闭流程；设置窗口关闭时不提交未保存的表单，自定义颜色窗口关闭时按取消处理。
