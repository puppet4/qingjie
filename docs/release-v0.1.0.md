# 轻截 Qingjie 0.1.0

一个用 Rust 编写的 Windows 原生截图工具。**253 KiB，一个 exe，打开就用。**

支持区域、全屏、上次区域与延时截图；画笔、形状、箭头、文字、马赛克、实色遮挡；自定义颜色、撤销/重做、剪贴板复制、无损 PNG 保存和置顶贴图。全局快捷键可以在设置中修改。

## 下载与使用

1. 下载附件 **qingjie.exe**（Windows 10/11 x64，259,072 字节）。
2. 双击运行，按 **Ctrl+Alt+A** 开始区域截图。
3. 标注后按 **Enter** 复制，或按 **Ctrl+S** 保存。

无需安装。右键托盘图标可打开设置、帮助或退出；更新前请先退出旧程序。

附件 `release.json` 提供程序的 SHA256 校验值。完整功能、图片和使用说明请查看仓库 README。

## 验证与边界

30 项常规回归测试及 Clippy 检查通过。本版本暂不提供 OCR、滚动长截图和截图历史；混合 DPI 多屏、HDR 与受保护桌面的覆盖范围见仓库验证说明。
